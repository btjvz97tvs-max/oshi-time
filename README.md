# 推しタイム

にじさんじの推しの「いま配信中」「配信予定」「新着」と、チケットやグッズの締切をひとつにまとめる非公式ファンアプリです。
GitHub Pages で動かし、iPhone のホーム画面に追加して使います。

## できること

- **推しを探す**：にじさんじ全員から名前で検索して推し登録（ひらがな・カタカナ・英語・漢字どれでもOK）
- **ホーム**：推しの配信中・3日先までの配信予定・新着動画。「にじさんじ全員」に切り替えも可能
- **締切**：申込期限などを登録すると、3日前からホームの「今日やること」に表示。iPhoneのカレンダーにも追加できる（前日と3時間前に通知）

にじさんじ全員（ID・KR出身、NIJISANJI EN を含む200人、2026年11月時点）の名簿を `livers.json` に入れてあるので、推しの検索と登録は設定なしですぐ使えます。
配信データは5分ごとに GitHub Actions が [Holodex](https://holodex.net) から自動で集めます。名簿にいない新人も、Holodex に載れば自動で検索に出てきます。
推し登録と締切はその端末の中だけに保存されます。

## はじめかた

1. **Holodex の APIキーを取る**
   holodex.net にログイン → 右上のメニューから Account Settings → API Key を発行してコピー
2. **GitHub にリポジトリを作る**（Public）
   このフォルダの中身をすべて入れる（`.github` フォルダも忘れずに）
3. **APIキーを登録**
   リポジトリの Settings → Secrets and variables → Actions → New repository secret
   名前：`HOLODEX_API_KEY`　値：1でコピーしたキー
4. **Pages を有効にする**
   Settings → Pages → Build and deployment の Source を「GitHub Actions」にする
5. **初回の更新を動かす**
   Actions タブ →「推しデータを更新して公開」→ Run workflow
6. 終わったら表示されるURL（`https://ユーザー名.github.io/リポジトリ名/`）を iPhone の Safari で開き、共有ボタン →「ホーム画面に追加」

## ファイル

| ファイル | 役割 |
|---|---|
| `index.html` | アプリ本体（画面・検索・締切） |
| `accounts.json` | アプリを使えるアカウントの一覧（申請コード＝公開鍵を並べる。名前は入れない） |
| `livers.json` | ライバー名簿。1行1人で、`n` 名前 / `k` よみ / `e` 英語表記 / `g` 期・ユニット / `yt` YouTubeチャンネルID / `yh` YouTubeハンドル（@の後ろ） / `a` 別名 |
| `scripts/fetch-data.mjs` | Holodex から全員分のデータを集めて、暗号化した `data.enc.json` を作る（アカウントがないときは `data.json`） |
| `.github/workflows/update.yml` | 5分ごとに上のスクリプトを動かしてサイトを公開し直す |
| `sw.js` / `manifest.webmanifest` / `icon-*.png` | ホーム画面に追加したとき用 |
| `vendor/` | 暗号の部品。パスワードの変換に使う Argon2（argon2-browser 1.18.0）と、暗号化に使う tweetnacl 1.0.3 |

## アカウント（使える人を決める）

`accounts.json` にアカウントが1つもないあいだは、誰でも使えます。1つでも入れると、登録された人だけが配信データを開けるようになります。

1. 使いたい人が、アプリの「アカウントを申請する」でアカウント名とパスワードを決め、出てきた**申請コード**を、自分の名前と一緒に管理者に送る
   （申請コードにはアカウント名もパスワードも入っていません）
2. 管理者が GitHub で `accounts.json` を開き、鉛筆ボタンで編集して、`"accounts": [` の次の行に申請コードを貼る。
   2人目からは、前の行の最後に `,` を付けてから次の行に貼る。`"old": true` と書かれた古い行があれば消す
3. 保存すると5〜10分で反映され、その人がログインできるようになる

ファイルには名前が残らないので、どの行が誰のものかは管理者の手元にメモしておいてください（`pub` の最初の数文字を控えておくと見分けられます）。
使えなくしたい人は、その人の行を消して保存します。次の更新（5〜10分後）から、その人は新しい配信データを開けなくなります。

**守り方**

- アカウント名とパスワードを、各自の端末の中で Argon2id（1回ごとに128MBのメモリを使って4回まわす変換）にかけて「秘密鍵」を作ります。
  `accounts.json` に置くのは、その秘密鍵から計算した**公開鍵**（`pub`）だけです。公開鍵から秘密鍵やパスワードを逆算することはできません。
- 配信データは、更新のたびにランダムな鍵で暗号化し（XSalsa20-Poly1305）、その鍵を、登録された人それぞれの公開鍵で包んで（X25519）、`data.enc.json` として公開します。
  平文の `data.json` は公開しません。秘密鍵を持っている人しか中身を開けないので、ログイン画面を飛ばしても、ファイルを直接読んでも、配信データは見えません。
- ログインした端末には秘密鍵だけを保存し、ログアウトすると秘密鍵と開いたデータを消します。
- 暗号の部品は `vendor/` にあります（argon2-browser と tweetnacl。どちらも公開されているライブラリで、ライセンスファイルも同じ場所にあります）。

**それでも公開されているもの**：アプリの画面（`index.html`）、ライバー名簿（`livers.json`、公式の公開情報）、`accounts.json` の公開鍵の数（＝登録人数）、
GitHub Actions の記録（配信の件数など。誰が配信中かは出していません）。
パスワードが短いと、公開鍵から総当たりで当てられる可能性があるので、長めのパスワード（12文字以上がおすすめ）にして、ほかのサービスと同じものは使わないでください。
推し登録と締切は各自の端末の中だけに保存されます。

2026年11月6日までに作った申請コード（`salt` や `check` が入っている古い形式）は使えないので、申請し直してください。

## 名簿を直したいとき

GitHub で `livers.json` を開いて鉛筆ボタンで編集します。たとえば新人を足すなら、最後の人の行の後ろに `,` を付けて次の行に
`{"n": "名前", "k": "よみがな", "g": "2026年12月デビュー", "yh": "YouTubeのハンドル"}` のように1行追加して保存すれば、数分でアプリに反映されます。
YouTubeのハンドルは、チャンネルのURL `youtube.com/@○○` の ○○ の部分です。
卒業した人は、その行を消してください。

## 注意

- 非公式のファンアプリです。広く公開したり収益化したりする前に「ANYCOLOR二次創作ガイドライン」を確認してください
- X（旧Twitter）の投稿は取得していません（公式APIが有料のため）。各ライバーの画面から X を開けます
